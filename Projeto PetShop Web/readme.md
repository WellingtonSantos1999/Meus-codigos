## Funcionalidades

O sistema possui as seguintes funcionalidades:

- Cadastro de Clientes
- Cadastro de Pets
- Cadastro de Funcionários
- Cadastro de Serviços
- Agendamentos
- Pagamentos

## Tecnologias utilizadas

- Java
- Spring Boot
- Thymeleaf 
- MySQL
- GitHub
